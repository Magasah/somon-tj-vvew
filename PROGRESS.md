## Как запустить и проверить

> Обновлять по мере появления команд.

```bash
# установка (Windows: .venv/Scripts/activate вместо source)
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env   # заполнить BOT_TOKEN и OWNER_CHAT_ID

# тесты и линтер
pytest
ruff check . && ruff format --check .

# справка
python -m jobbot --help

# один опрос без базы и отправки (токен не нужен): печатает вакансии страницы 1 каждого раздела
# ходит на реальный somon.tj: robots.txt + по 1 странице на раздел, пауза 3 с
python -m jobbot --once --dry-run

# ручная проверка Telegram (нужны BOT_TOKEN и OWNER_CHAT_ID в .env): придут 2 тестовых сообщения
python tests/manual_send_card.py

# один настоящий опрос с базой и отправкой (нужен .env), затем выход
python -m jobbot --once

# запуск бота (опрос по кругу + команды)
python -m jobbot

# Docker
mkdir -p data && docker compose up -d --build
docker compose logs -f
docker compose restart
```

## Заметки по парсеру

> Обновлять, если сайт поменяет вёрстку. Фикстуры — реальные страницы, скачаны 2026-10-05 через `Fetcher`.

- Фикстуры: `tests/fixtures/it_page1.html` (60 карточек), `students_page1.html` (55), `robots.txt`.
- Сайт — React/Next с потоковым SSR; классы Tailwind (`flex gap-2 ...`) нестабильны, на них не опираемся. Опора: `data-component`, `itemprop`, структура.
- Карточка: `[data-component^="JobCard"]` (на странице `JobCardDesktop`; `JobCardMobile` — на всякий случай). Внутри `itemscope itemtype=schema.org/JobPosting`.
- Ссылка: `a[itemprop="url"]` внутри карточки, `href="/adv/<id>_<slug>/"`; `ad_id` — регулярное выражение `/adv/(\d+)_`; URL приводится к `https://somon.tj/adv/<id>_<slug>/` (без query/fragment), чужие домены отбрасываются.
- Заголовок: `meta[itemprop="title"]` → `content`; запасной вариант — текст ссылки (`span.sr-only`). Заголовок может отличаться от слага в URL (правят после публикации).
- Зарплата: первый `div` карточки → второй дочерний элемент (строка с меткой VIP/ТОП и ценой) → последний `span` без `data-slot` («5 000 c.», «3 000 - 4 000 c.», «Договорная»). Метка VIP/ТОП — `span[data-slot="tag"]`, её может не быть.
- Дата и город: последний `<p>` карточки: «Сегодня <svg> Душанбе» → текстовые узлы: первый = дата («Сегодня», «Вчера», «2 дня назад», «4 недели назад»), последний = город. Если узел один — считается датой.
- Описание вакансии лежит в карточке (`meta[itemprop=description]`, первый `p`) — сейчас не используется (ТЗ: фильтр только по заголовку).
- Ловушка: в JSON внутри страницы (`<script>` RSC-потока) лежат ссылки `/adv/…` на товары из других разделов (галереи): 96 уникальных ID в «сыром» HTML против 60 карточек. Поэтому запасной парсер берёт только настоящие `<a href>` из DOM, а не regex по всему тексту.
- Запасной парсер: все `a[href]` с `/adv/\d+_`, текст ссылки как заголовок, без зарплаты/города/даты; результат помечается `simplified=True`.
- robots.txt (2026-10-05): закрыты `/api`, `/admin`, `/profile`, `/edit`, `/hide`, `/public-adv`, `/mobile_search/`, `/saved_search/`, `/static/`, `/?page=` (только корень), `*---*`, `/*?ordering`, `/*price_min`, `/*price_max`, `/*attrs__`, `*/author/`. Разделы и `?page=N` разрешены. `urllib.robotparser` не понимает `*`, поэтому `check_url_allowed` дополнительно режет `---`, запрещённые пути и любые параметры, кроме `page`.
- Дата проверки селекторов: 2026-10-05

## Решения

> Формат: дата · решение · почему · какие варианты отклонены.

- 2026-10-05 · Сбор только с публичных страниц разделов, без входа в аккаунт · безопасность аккаунта, соблюдение robots.txt · вход через аккаунт отклонён.
- 2026-10-05 · Новизна объявления определяется по `ad_id` из URL · поднятые старые объявления не приходят повторно.
- 2026-10-05 · Python локально 3.14 (в ТЗ 3.12): код пишем совместимо с 3.12 (`target-version=py312`), в Docker будет 3.12 · на машине нет 3.12.
- 2026-10-05 · Версии зависимостей закреплены по факту установки: aiogram 3.31.0, httpx 0.28.1, selectolax 1.0.0, aiosqlite 0.22.1, pydantic-settings 2.15.0, tzdata 2026.5 (нужен для `ZoneInfo` на Windows).
- 2026-10-05 · Dev-зависимости вынесены в `requirements-dev.txt`, чтобы Docker-образ не тянул pytest/ruff.
- 2026-10-05 · Маскировка токена сделана в `SafeFormatter` (маскирует итоговую строку, включая traceback) + `TokenMaskFilter` · обычный фильтр не видит текст исключений. Логи httpx/httpcore понижены до WARNING, т.к. URL Telegram содержит токен.
- 2026-10-05 · `--dry-run` не требует `BOT_TOKEN`/`OWNER_CHAT_ID` (Telegram не используется); без него пустые токен/chat_id → понятная ошибка, код 1.
- 2026-10-05 · Разделы (`DEFAULT_CATEGORIES`) заданы кодом в `config.py`, не через .env · добавление раздела = одна строка; ТЗ не требует env для них.
- 2026-10-05 · `selectolax` 1.0: бэкенд Modest удалён, используем `selectolax.lexbor.LexborHTMLParser` (CSS-селекторы те же) · BeautifulSoup не понадобился.
- 2026-10-05 · Повторы в fetcher: первая попытка + 3 повтора с паузами 2/4/8 с (+0–1 с джиттера) · ТЗ «3 попытки с задержками 2, 4, 8» трактовано как три паузы. 4xx кроме 403/429 — без повторов (`HttpStatusError`); отсутствие robots.txt (4xx) = ограничений нет; недоступность robots.txt при пустом кеше → запросы к страницам не идут.
- 2026-10-05 · `parse_page()` объединяет основной и запасной парсеры и возвращает флаг `simplified` (для пометки «(упрощённый режим)» на этапе 6); основной `parse_listing()` соответствует сигнатуре из ТЗ.
- 2026-10-05 · Сопоставление слов (`matcher.py`): слово должно начинаться на границе слова, окончания разрешены (`разработчик` → «разработчика»); слова ≤3 символов (`it`, `web`, `1с`) — только целиком; границы проверяются лишь у букв/цифр (работают `c#`, `.net`, `c++`) · иначе `it` находился бы в «digital»/«credit». Отклонено: простой поиск подстроки; полноценная лемматизация (избыточно).
- 2026-10-05 · Режим `keywords` с пустым include не пропускает ничего; exclude приоритетнее include в любом режиме.
- 2026-10-05 · `storage.py`: одно подключение, `isolation_level=None` + явные `BEGIN IMMEDIATE`/`COMMIT`, все обращения под `asyncio.Lock` (чтения тоже — чтобы не видеть чужую незавершённую транзакцию). Слова хранятся нормализованными. Время — `YYYY-MM-DDTHH:MM:SSZ` (UTC), сравнивается как текст.
- 2026-10-05 · `add_ads(items, sent=...)`: объявления первого запуска (seed) сохраняются сразу с `sent_at` — иначе «досылка `sent_at IS NULL`» при старте отправила бы их как новые. Поэтому они видны в `/last`.
- 2026-10-05 · `seed_defaults`: разделы добавляются при каждом старте, если их нет (настройки существующих не трогаются); слова include/exclude — один раз (флаг `defaults_seeded` в `state`), удалённое владельцем слово не возвращается после перезапуска.
- 2026-10-05 · `Notifier.send_ads` возвращает `ad_id` реально доставленных; вызывающий (poller) делает `mark_sent` только для них (раздел 4.2 ТЗ). Ошибки: `TelegramBadRequest` на одной карточке → пропуск, остальные идут; прочие `TelegramAPIError`/сеть → отправка прерывается, остаток досылается позже; сбой дайджеста → не помечается ничего (лучше повтор, чем потеря). `TelegramRetryAfter`: ждём указанное время, до 3 попыток.
- 2026-10-05 · Дайджест (> `DIGEST_THRESHOLD`, т.е. строго больше 8): строки «• название — ссылка», делится по строкам с лимитом 4000 символов (запас до 4096), превью ссылок отключено. Ссылки не из `https://somon.tj/adv/` не отправляются и не помечаются.
- 2026-10-05 · Добавлен `tests/manual_send_card.py` (ТЗ требует ручную проверку карточки, а точки входа для неё не было) · альтернатива — флаг `--test-card` в `__main__` отклонена как лишняя функция бота.
- 2026-10-05 · Seed-заголовок «Последние вакансии в разделе …» добавляется сверху первой карточки, а не отдельным сообщением (изменён `Notifier.send_ads(header=...)`) · критерий этапа 4 требует ровно `SEED_SEND_LAST` сообщений. «Последние» = наибольшие `ad_id`, т.к. порядок на странице смешан с VIP/ТОП.
- 2026-10-05 · Единый путь отправки в poller: новые объявления кладутся в базу с `sent_at=NULL`, затем `_send_pending()` шлёт ВСЁ подходящее неотправленное за 24 ч (новые + то, что не ушло раньше из-за сбоя) и ставит `sent_at` только доставленным. Так доотправка работает не только при старте, но и каждый цикл; дайджест-порог считается по общему списку цикла.
- 2026-10-05 · Страницы 2–3 берутся, только если ВСЕ объявления страницы новые (раздел 2.4); это же правило действует и при seed (первый запуск: до `MAX_PAGES` страниц на раздел, иначе поднятые старые объявления позже пришли бы как новые). Пауза (`paused=1`): опрос и запись в базу идут, отправки нет.
- 2026-10-05 · Пауза 30 минут после 403/429 реализована уже в poller (state `blocked_until`, цикл пропускается без запросов) — это безопасность сайта; уведомление владельцу «один раз» остаётся на этап 6. Любая ошибка раздела пишется в state `last_error` (для `/status`).
- 2026-10-05 · Объявления запасного парсера отправляются отдельной группой с пометкой «(упрощённый режим)».
- 2026-10-05 · `/resume` досылает накопленное с момента `/pause` (state `paused_at`), но не глубже 7 дней; без `paused_at` — 24 ч. Сначала бот отвечает «Накопленных вакансий: N, отправляю», затем идёт отправка (дайджест при N > 8).
- 2026-10-05 · Доступ: `OwnerOnlyMiddleware` на `dispatcher.message` и `dispatcher.callback_query` (outer, до фильтров), сверка по `chat.id`; чужим — ни ответа, ни `answer_callback_query`, только WARNING. Команды и кнопки владельца используют HTML-ответы, пользовательский текст экранируется.
- 2026-10-05 · Самодиагностика в poller: пустая страница 1 → `empty_streak:<cat>` (3 подряд → предупреждение, не чаще 6 ч, `last_alert_at:empty:<cat>`); ошибки загрузки → `fetch_fail_streak` (5 подряд → одно уведомление, при первой удачной загрузке — «✅ Связь с сайтом восстановлена»); 403/429 → одно уведомление на «эпизод» (флаг `block_alerted` снимается после успешной загрузки); robots.txt запретил раздел → не чаще раза в 24 ч. Служебные уведомления идут и на паузе; ошибка их отправки не ломает опрос.
- 2026-10-05 · Остановка: SIGINT/SIGTERM → `stop` → `dispatcher.stop_polling()` + ожидание задачи опроса до 30 с (`SHUTDOWN_TIMEOUT_SEC`), затем закрытие HTTP-клиента, сессии бота и базы. На Windows обработчики ставятся через `signal.signal` + `call_soon_threadsafe`. При неверном токене (`getMe` → Unauthorized) бот пишет понятную ошибку и выходит с кодом 1.
- 2026-10-05 · Docker: uid 1000, `DB_PATH=/app/data/jobbot.db` задаётся в compose, volume `./data`; `stop_grace_period: 40s` > 30 с ожидания бота. На Linux каталог `data` должен принадлежать uid 1000 (описано в README).
- 2026-10-05 · Первый запуск сохраняет текущие объявления без отправки (кроме `SEED_SEND_LAST`) · защита от спама сотнями старых вакансий.
