# Somon Job Alert Bot

Личный Telegram-бот: каждые ~5 минут смотрит выбранные разделы вакансий на [somon.tj](https://somon.tj),
находит **новые** объявления, фильтрует по вашим словам и сразу присылает карточку со ссылкой.
Бот отвечает только вам — остальным молчит.

Что нужно: компьютер или сервер, который работает постоянно (для круглосуточных уведомлений),
Telegram-аккаунт и 15 минут.

---

## 1. Получите токен бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя и логин бота (логин должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...`. Это пароль от бота — никому его не показывайте
   и не выкладывайте в интернет.

## 2. Узнайте свой chat_id

1. Откройте [@userinfobot](https://t.me/userinfobot) и отправьте `/start`.
2. Он ответит числом в поле `Id` — это ваш `OWNER_CHAT_ID`.
3. **Обязательно** откройте своего нового бота и нажмите **Start** (или отправьте `/start`).
   Пока вы не написали боту первым, Telegram не разрешит ему писать вам.

## 3. Настройте `.env`

Скопируйте шаблон и впишите два значения:

```bash
cp .env.example .env        # Windows (cmd): copy .env.example .env
```

Откройте `.env` в любом редакторе и заполните:

```
BOT_TOKEN=123456789:AAH...ваш_токен
OWNER_CHAT_ID=123456789
```

Остальные настройки можно не трогать:

| Переменная | По умолчанию | Что значит |
|---|---|---|
| `POLL_INTERVAL_SEC` | 300 | Как часто опрашивать сайт, секунды (не меньше 180) |
| `POLL_JITTER_SEC` | 60 | Случайный разброс ± к интервалу |
| `REQUEST_DELAY_SEC` | 3 | Пауза между запросами к сайту (не меньше 3) |
| `MAX_PAGES` | 3 | Сколько страниц раздела смотреть, если все объявления новые (1–5) |
| `SEED_SEND_LAST` | 3 | При первом запуске раздела прислать столько последних вакансий (остальные запоминаются молча) |
| `DIGEST_THRESHOLD` | 8 | Если новых за цикл больше — прислать одним сообщением-списком |
| `DB_PATH` | `data/jobbot.db` | Где лежит база |
| `LOG_LEVEL` | INFO | Подробность логов |
| `TZ` | Asia/Dushanbe | Часовой пояс для логов и `/status` |

`.env` в git не попадает (он в `.gitignore`). Не отправляйте его другим людям.

## 4. Запуск

### Вариант А. Docker (рекомендуется для сервера)

Нужны Docker и Docker Compose.

```bash
mkdir -p data               # папка для базы (Windows: mkdir data)
docker compose up -d --build
docker compose logs -f      # смотреть логи (выход: Ctrl+C, бот продолжит работать)
```

Бот перезапускается сам после сбоев и перезагрузки сервера (`restart: unless-stopped`).
После `docker compose restart` дубли не приходят: база лежит в `./data`.

> На Linux контейнер работает от пользователя с uid 1000. Если в логах «unable to open database
> file», выполните `sudo chown -R 1000:1000 data`.

### Вариант Б. Локально без Docker

Нужен Python 3.12 или новее.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m jobbot
```

Остановить: `Ctrl+C` (бот дождётся конца текущего опроса и закроется аккуратно).

### Проверка без риска

```bash
python -m jobbot --once --dry-run
```

Один опрос сайта: выводит найденные вакансии в консоль, **ничего** не пишет в базу и не отправляет
(токен для этого режима не нужен). Если здесь вы видите список вакансий — парсер и сеть работают.

```bash
python -m jobbot --once
```

Один настоящий опрос с записью в базу и отправкой, после чего программа завершается.

## 5. Что будет при первом запуске

Бот **не завалит вас сотнями старых вакансий**. Для каждого раздела он запоминает все текущие
объявления и присылает только последние 3 (`SEED_SEND_LAST`) с подписью «Последние вакансии в разделе …»,
чтобы вы увидели, что всё работает. Дальше приходит только то, чего раньше не было.

## 6. Команды бота

Команды работают только из вашего чата.

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Справка |
| `/status` | Время последнего опроса, объявлений в базе, отправлено сегодня, пауза, последняя ошибка |
| `/check` | Опросить сайт прямо сейчас (не чаще раза в минуту) |
| `/pause`, `/resume` | Остановить / возобновить уведомления. Во время паузы опрос идёт, новые вакансии копятся и приходят после `/resume` |
| `/filters` | Показать слова include/exclude и режимы разделов |
| `/include слово` | Добавить слово в include |
| `/exclude слово` | Добавить слово в exclude |
| `/remove слово` | Удалить слово из обоих списков |
| `/categories` | Кнопки: включить/выключить раздел, переключить режим `all` / `keywords` |
| `/last [n]` | Прислать последние n (1–20, по умолчанию 5) подходящих вакансий из базы |

**Как работает фильтр.** Слово из **exclude** отклоняет вакансию всегда. Режим раздела:
`all` — приходят все вакансии, кроме exclude; `keywords` — только те, где есть слово из include.
Слова сравниваются без учёта регистра и `ё`/`е`; «разработчик» находит и «разработчика».
Короткие слова (`it`, `web`, `1с`) ищутся только как отдельное слово.
Слово: от 2 до 40 символов, буквы/цифры/пробел/`-`/`+`/`#`/`.`, не больше 100 слов в списке.

По умолчанию оба раздела в режиме `all`. Чтобы получать только программистские вакансии,
откройте `/categories` и переключите режим на `keywords`.

## 7. Как добавить свой раздел

1. Откройте нужный раздел вакансий на somon.tj и скопируйте адрес без параметров, например
   `https://somon.tj/vakansii/prodazhi/`. Адрес не должен содержать `?ordering=`, `price_min` и т.п.
   (они запрещены в `robots.txt`).
2. В файле `jobbot/config.py` добавьте строку в `DEFAULT_CATEGORIES`:

   ```python
   DEFAULT_CATEGORIES = (
       # ... существующие разделы ...
       Category(key="sales", title="Продажи", url=f"{BASE_URL}/vakansii/prodazhi/"),
   )
   ```

3. Перезапустите бота (`docker compose up -d --build` или `python -m jobbot`).
   Новый раздел появится в `/categories`, а при первом опросе сработает «тихий» старт (без спама).

## 8. Как бот ведёт себя с сайтом

- Только публичные страницы, без входа в аккаунт.
- Не чаще 1 запроса в 3 секунды, последовательно; `robots.txt` проверяется раз в сутки.
- Честный `User-Agent: SomonJobAlertBot/1.0 (personal use)`; без прокси и обхода капчи.
- Если сайт отвечает 403/429, бот делает паузу 30 минут и один раз пишет вам об этом.

## 9. Уведомления об ошибках

Бот сам напишет, если:

- парсер раздела три цикла подряд не находит объявлений (возможно, сайт поменял вёрстку);
- 5 сетевых ошибок подряд (и потом «✅ Связь с сайтом восстановлена»);
- сайт ограничил доступ (403/429) или `robots.txt` закрыл раздел.

Если основной парсер не нашёл карточки, но на странице есть ссылки на объявления, включается
упрощённый режим — такие вакансии помечаются «(упрощённый режим)».

## 10. Обновление

```bash
git pull                              # или замените файлы проекта
docker compose up -d --build          # без Docker: pip install -r requirements.txt и перезапуск
```

База и настройки фильтров (в `data/`) сохраняются.

## 11. Частые проблемы

| Симптом | Что делать |
|---|---|
| При запуске: «BOT_TOKEN: не задан» | Заполните `.env` (шаг 3) |
| «Telegram отклонил BOT_TOKEN» | Токен скопирован неверно — возьмите заново у @BotFather (`/mybots` → ваш бот → API Token) |
| Бот запущен, но сообщения не приходят | Вы не нажали **Start** у своего бота; либо в `OWNER_CHAT_ID` чужое число (проверьте через @userinfobot) |
| В логах `Forbidden: bot was blocked by the user` | Вы заблокировали бота — разблокируйте и нажмите Start |
| Бот не отвечает на команды | Команды принимаются только из чата `OWNER_CHAT_ID`; в логах будет `игнорирую событие из чужого чата` |
| Пришло предупреждение «не нашёл объявлений 3 раза подряд» | Сайт мог поменять вёрстку: запустите `python -m jobbot --once --dry-run`; если пусто — нужно обновить `jobbot/parser.py` (см. «Заметки по парсеру» в `PROGRESS.md`) |
| «Сайт ответил 429/403» | Бот сам подождёт 30 минут. Не уменьшайте интервалы опроса |
| Хочется начать «с нуля» (снова получить «тихий» старт) | Остановите бота и удалите папку `data/` (слова фильтра тоже сбросятся) |
| Docker: «unable to open database file» (Linux) | `sudo chown -R 1000:1000 data` |
